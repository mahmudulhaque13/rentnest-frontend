# RentNest

RentNest is a rental property management platform for tenants, landlords, and admins.

## Live Site

Frontend: YOUR_FRONTEND_URL

Backend: YOUR_BACKEND_URL

## Features

- User registration and login
- Role-based access: Tenant, Landlord, Admin
- Property search and filtering
- Property details
- Rental request management
- Stripe payment integration
- Property reviews
- Landlord property management
- Landlord earnings
- Admin user management
- Admin property management
- Admin rental request management
- Admin category CRUD
- Responsive design

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- Prisma
- JWT
- Stripe

## Installation

```bash
git clone YOUR_FRONTEND_GITHUB_URL
cd rentnest-frontend
npm install

Create .env.local:

BACKEND_API_URL=YOUR_BACKEND_URL
JWT_ACCESS_SECRET=YOUR_JWT_ACCESS_SECRET

Run the project:

npm run dev

Open:

http://localhost:3000

API Documentation

See:

API_INTEGRATION.md
Admin Credentials
Email: YOUR_ADMIN_EMAIL
Password: YOUR_ADMIN_PASSWORD
```
